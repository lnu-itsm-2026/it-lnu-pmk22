# Runbook — шаблон

> Скопіюйте цей файл у `services/<ваш сервіс>/runbooks/<коротка-назва>.md` і заповніть.
> Runbook пишуть для людини, яка прийде о третій ночі й ніколи не бачила цієї проблеми.
> Якщо після прочитання їй усе одно треба комусь дзвонити, щоб зрозуміти перший крок, —
> runbook не готовий.

## Коли застосовувати

Як симптом виглядає **для користувача** і **в моніторингу**. Цифри, текст помилки.
